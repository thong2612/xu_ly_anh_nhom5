# Ảnh demo: nguồn và giấy phép

Các ảnh dưới đây được sao chép nguyên trạng từ dataset nguồn. Chúng chỉ là ví dụ để thử giao diện, không phải tập đánh giá độc lập.

- `sample_ripeness.jpg` — A. Prabhu, “Alphonso Mango Ripening Stage Classification Dataset,” Mendeley Data, Version 1 (2024), [DOI 10.17632/tyghd6gxw2.1](https://doi.org/10.17632/tyghd6gxw2.1). Giấy phép nguồn: CC BY 4.0.
- `sample_defect.jpg` — P. Ankunda et al., “Mango classification and segmentation dataset in Uganda,” Mendeley Data, Version 1 (2026), [DOI 10.17632/cy3ccgkx3n.1](https://doi.org/10.17632/cy3ccgkx3n.1). Giấy phép nguồn: CC BY 4.0.

Nguồn: [Dataset A trên Mendeley Data](https://data.mendeley.com/datasets/tyghd6gxw2/1) và [Dataset C trên Mendeley Data](https://data.mendeley.com/datasets/cy3ccgkx3n/1). Các tệp mẫu được chép không chỉnh sửa; tên file đã rút gọn cho tiện sử dụng.
